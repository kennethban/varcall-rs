# variant-rs

variant-rs is a reimplementation of GATK 4.7 and Picard tools in Rust, with a CUDA PairHMM, whose outputs are
byte-identical to those of GATK. It accepts the command lines of GATK:

```bash
variant-rs MarkDuplicates -I S1.bam -O S1.md.bam -M S1.md.metrics
variant-rs BaseRecalibrator -R ref.fa -I S1.md.bam --known-sites dbsnp.vcf.gz -O S1.recal.table
variant-rs HaplotypeCaller -R ref.fa -I S1.md.bam --bqsr-recal-file S1.recal.table -O S1.g.vcf.gz -ERC GVCF
variant-rs Mutect2 -R ref.fa -I T.bam -I N.bam -normal N --germline-resource af-only-gnomad.vcf.gz -O T.vcf.gz
variant-rs <Tool> --help                       # what is supported for that tool
GATK_FALLBACK=/path/to/gatk variant-rs ...     # anything not reproduced exactly runs the real GATK
```

It provides 23 tools ([supported arguments of each tool](../docs/reference.md#gatk-command-lines)):

* **Preprocessing:** MarkDuplicates, BaseRecalibrator, ApplyBQSR, GatherBQSRReports, SortSam, GatherBamFiles.
* **Germline:** HaplotypeCaller, ReblockGVCF, GenomicsDBImport, GenotypeGVCFs (GVCF files and GenomicsDB
  workspaces), VariantRecalibrator, ApplyVQSR, VariantFiltration, MakeSitesOnlyVcf, MergeVcfs.
* **Somatic:** Mutect2, CreateSomaticPanelOfNormals, FilterMutectCalls, LearnReadOrientationModel,
  GetPileupSummaries, GatherPileupSummaries, CalculateContamination, MergeMutectStats.

| | |
|---|---|
| `src/gatk_cli.rs`, `gatkargs/` | GATK command lines: argument tables, translation, refusals, fallback |
| `src/main.rs`, `frontend.rs`, `active.rs`, `backend.rs`, `rng.rs`, `plan.rs` | HaplotypeCaller driver: contigs in parallel, regions, RNG domains, shard planner |
| `crates/` | HaplotypeCaller stages: preproc, assembly, likelihood, cudahmm, genotype, refconf, downsample ([README](crates/README.md)) |
| `cuda-pairhmm/` | the CUDA PairHMM, bit-exact with GATK's (GKL) AVX-512 kernel; a pool of engines over every visible GPU |
| `src/mutect/` | Mutect2, FilterMutectCalls, contamination, orientation model |
| `src/markdup/`, `src/bqsr/` | MarkDuplicates; BaseRecalibrator, ApplyBQSR, GatherBQSRReports |
| `src/genotypegvcfs.rs`, `gdb_store.rs`, `gdb_merge.rs`, `reblock.rs` | joint genotyping, GenomicsDB reader, ReblockGVCF |
| `src/mergevcfs.rs`, `sortsam.rs`, `gatherbam.rs`, `filter.rs` | Picard tools, hard filters |
| `src/bam.rs`, `bamwrite.rs`, `bgzf.rs`, `tabix.rs`, `cram.rs`, `csrc/` | BAM / BGZF / tabix / CRAM I/O (htsjdk's encodings) |
| `tables/` | tables generated by GATK (`GenTables.java`), header templates |
| `tests/` | CLI checks against GATK, review fixes, Java-math tests |

To build, run `make -C cuda-pairhmm` (optional) and then `cargo build --release` from the repository root. Further
documentation: [docs/reference.md](../docs/reference.md), [docs/architecture.md](../docs/architecture.md),
[docs/optimizations.md](../docs/optimizations.md) and the [development notes](../docs/notes/variant-rs.md), which
record each GATK behaviour reproduced and how it was validated.
